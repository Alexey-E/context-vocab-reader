## Pull request merge policy

- Never merge a functional pull request autonomously.
- After implementation and required checks pass, open or update the pull request, report that it is ready, and stop before merging.
- Merge a functional pull request only after the user explicitly requests the merge of that specific pull request. General instructions such as "continue", "finish the stage", or "complete the task" do not authorize a merge.
